# Magpie v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An iOS 27 SwiftUI + CarPlay app that plays the owner's Navidrome library and lets them Try / Keep songs through their Lidarr, delivered as milestones M0–M8, each tagged green.

**Architecture:** One local Swift package `Packages/MagpieKit` (platform-neutral modules tested with `swift test`, UI modules tested on the simulator) + an XcodeGen-generated app target with a CarPlay scene. Pure models and state machines; effects in actors; every Lidarr write behind one gate.

**Tech Stack:** Swift 6.3 (strict concurrency), SwiftUI (@Observable), AVFoundation (AVQueuePlayer), MediaPlayer, CarPlay, Security (Keychain), CryptoKit (MD5 for Subsonic token), Swift Testing. **No third-party dependencies.** XcodeGen 2.46. Xcode 27.1, iOS 27.1 simulator.

**Spec:** `docs/superpowers/specs/2026-10-27-magpie-v1-build-design.md` **plus** `docs/reviews/v1-decision-review.md` (API corrections A1–A17 and guards G0–G9 override the spec where they differ). Design: `docs/storyboard/design-language.md`, `docs/storyboard/carplay.md`, accessibility table in `docs/reviews/design-critique-accessibility.md`. Decisions: `docs/decisions.md`.

## Global Constraints

- Every shell that runs Xcode tools: `export DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer` (xcode-select points to CLT; B1).
- Deployment target iOS 27.0; package platforms `.iOS(.v27), .macOS(.v27)`. Swift language mode 6.
- Bundle id `com.bleak-rooster.magpie`; display name **Magpie**; no custom keychain access group (B7).
- Keychain items `kSecAttrAccessibleAfterFirstUnlockThisDeviceOnly`; files written with `.completeFileProtectionUntilFirstUserAuthentication`.
- Info.plist: `NSAppTransportSecurity.NSAllowsLocalNetworking = YES`; Debug configuration only adds `NSAllowsArbitraryLoads = YES` (B2); `NSLocalNetworkUsageDescription` = "Magpie connects to your music server on your home network."; `UIBackgroundModes = [audio]`.
- Entitlement `com.apple.developer.carplay-audio = true` (simulator only needs it in the file; B7).
- Never log credentials: redact query items `u t s p apiKey token password` and headers `X-Api-Key`, `X-ND-Authorization`, `Authorization` (spec §5).
- Copy follows `docs/storyboard/design-language.md` §5 voice: never show service names outside Connect/Settings; "Not in your library", "Bringing it home", "Finds", "New finds", "Keep", "Not for me", tier names Quick fetch / Standard / Patient.
- Every not-yet / find / on-its-way item shows text status + SF Symbol, not shape alone (D3, D15).
- Tests touching a server run only when `MAGPIE_IT=1`, read `dev/.env.local`, and abort unless host ∈ {127.0.0.1, localhost} and the dev marker matches (G0).
- Lidarr writes only via `LidarrWriteGate` (G1), which defaults to off. Never call: `DELETE /artist/editor`, `DELETE /artist?deleteFiles=true`, `addImportListExclusion=true`, `DELETE /api/missing`, any PUT to owner config endpoints listed in G5.
- Commit after each task; message ends with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Tag each milestone `m0`…`m8` only when `scripts/test-all.sh` is green, and update `docs/RUNBOOK.md` "What works" in the same commit.

## Review Focus

1. **Reverse-proxy base path** (`https://host/navidrome`): every request keeps the base path — test in Task 0.2 (`EndpointTests.keepsBasePath`).
2. **Token expiry / 401 storm mid-session**: one silent re-login (single-flight) then retry once; concurrent 401s trigger one login — test in Task 1.2 (`NavidromeAuthTests.concurrent401sLoginOnce`).
3. **Server unreachable / switching addresses mid-play**: first answering address wins; playback item URLs rebuilt from the active base — test in Task 0.2 (`EndpointTests.failoverOrder`) and Task 1.3 (`PlayerTests.rebuildsURLsAfterFailover`).
4. **Unicode and missing MBIDs** (accents, CJK, no MBID, M4A album without IDs): match ladder falls back to normalised artist+title+duration — test in Task 4.3 (`MatchLadderTests.unicodeAndNoMBID`).
5. **Lidarr path confinement with sibling/nested paths** (`/music/samples-old`, symlink, nested root): deletes and moves refused — test in Task 6.1 (`PathGuardTests`).
